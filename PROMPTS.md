## 1st Prompt:

“ROLE: You are a senior front-end developer building a React web app. GOAL: Build the front end of a cafe reservation tracker, a web product that lets anyone check whether a cafe has any reservations left. Their job on this product is to let users see whether a specific cafe has any reservations available for the day. Screens: [SCREEN 1: the homepage that shows all the other outlets] [SCREEN 2: show the reservation available for a specific outlet] OUTPUT: A running app. Keep every invented value in ONE data file of its own, with at least 10 rows, so the screen looks real. One component per screen or section. Move between screens without reloading the page. Readable on a phone at arm's length. When you are done, list the files you created and what each one holds. GUARDRAILS: Screens and invented data only. Do NOT call the Gemini API or any other model. Do NOT call any outside service or fetch from any URL. No database, no login, no user accounts, no analytics. No features I did not list. No real company's name, logo, or trademark. Invented names and numbers only, nothing confidential. CONTEXT: Individual Problem Set 1 for MGMT 6110 Human-AI Collaboration at SMU. Built in Google AI Studio, shared as a link, and opened on a phone by classmates in Week 3. I am not a programmer: when you make a choice I did not specify, say so in one line rather than burying it.”

**Result:** Built a cafe reservation tracker with a homepage showing multiple cafe outlets and a detail page showing the available reservation time slots for each cafe.

## 2nd Prompt:

“Make all address and phone numbers in the app fake. Change nothing else.”

**Result:** Replaced all addresses and phone numbers with fictional information while keeping the rest of the app unchanged.

## 3rd Prompt:

“Change the location on the homepage to fictional ones as well. Change nothing else.”

**Result:** Replaced the cafe neighbourhood and location names on the homepage with fictional locations.

## 4th Prompt:

“Add a light/dark mode to the header. Change nothing else.”

**Result:** Added a light and dark mode toggle in the header that allows users to switch between the two display modes.

## 5th Prompt:

“Add a ‘Last updated’ timestamp to the UI that simulates when the data was last checked, updated automatically when the user refreshes or switches views. Change nothing else.”

**Result:** Added a “Last updated” timestamp that refreshes when the page loads or when the user switches between the homepage and cafe detail screens.

## 6th Prompt:

“Change the colors of the header, search bar, and cafe tabs when in light mode. Change nothing else.”

**Result:** Updated the light-mode colours of the header, search bar and cafe availability tabs while keeping dark mode unchanged.

## 7th Prompt:

“Make the app adjust accordingly in different device preview such that nothing spills out. Change nothing else.”

**Result:** Improved the responsive layout so the interface adapts to different screen sizes without text, cards or other elements spilling outside the screen.

## 8th Prompt:

“Remove all scrollbars in the app. Change nothing else.”

**Result:** Removed visible scrollbars throughout the app while keeping scrolling functionality available.

## 9th Prompt:

“Remove this component. Change nothing else.”

**Result:** Removed the selected introductory banner from the homepage without changing the other parts of the interface.
